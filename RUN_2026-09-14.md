# Improvement Run — 2026-09-14

This run reviewed the v0.1 contract without adding hardware claims.

## Gap found

A granted capability family could previously accept any operation string submitted under that family. For example, a grant for `ui.navigate` did not itself prove that an arbitrary operation named under that family was authorized.

## Change

v0.1.1 requires granted capabilities to enumerate explicit operations and the structural request gate now blocks operations outside that set.

The run also added a continuity validator that checks an `ActionReceipt` against the exact `ActionRequest` using request ID, device ID, and deterministic request digest.

## Evidence

- local isolated unit run: 9 tests passed;
- no real Android device was used;
- no claim of real-device control is made;
- next hardware-dependent step remains the ARTEMIS before/action/after/trace baseline.
